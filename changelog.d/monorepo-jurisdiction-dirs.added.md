`load_corpus_from_roots` now requires explicit, absolute, unaliased country-monorepo checkouts named exactly `rulespec-<country>`. It indexes only atomic `rulespec/v1` `.yaml` modules in each jurisdiction's `legislation/`, `policies/`, `regulations/`, and `statutes/` roots. Declarative `programs/` specs remain canonical filesystem content but are excluded from the atomic corpus. Flat jurisdiction repositories, repository-root content, `.yml`, symlinks, duplicate countries, ambient root discovery, and empty corpora fail closed.
