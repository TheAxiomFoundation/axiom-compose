The `data_relation` pattern accepts `arguments` (one UpperCamelCase entity kind per tuple slot, in tuple order, length equal to `arity`) and emits them, so compositions can declare the typed relations axiom-rules-engine now requires (#33). Compose refuses an untyped composition-level `data_relation` that a composed rule aggregates (a formula names it, or a `derived_relation` filters it). Two imported `data_relation`s with the same name refuse when their arity differs or both declare different `arguments`; a typed declaration beside an untyped one issues a `ComposeWarning` instead, until the corpus types `us:statutes/7/2012/j#member_of_household`.
